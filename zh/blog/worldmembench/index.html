WorldMemBench: A Comprehensive Benchmark for Memory of Video World Models

当前的视频世界模型已能生成半分钟、可自由探索的场景。镜头移开再返回后，场景是否保持不变，此前正在发生的事件是否继续发展，正是 WorldMemBench 测量的内容。

要点

视频世界模型生成的是可在其中移动的世界。移动意味着内容会移出画面，随后又重新进入。仅能生成高质量单帧的模型，仍可能记错人物面貌、替换物体、改变房间布局，或在镜头移开期间使本应持续的事件停滞。

WorldMemBench 直接检验这一能力。基准包含 23 个类别共 260 个样例，相机沿受控路径离开已观察的内容并返回，一次或多次。静态内容包括人物、物体和场景，每次返回均与起始时的同一参考比对。动态事件如翻书、冰块融化，按样例设置专门问题，检查事件在视野之外是否继续推进。视频质量与相机跟随精度同时报告，作为解读记忆分数的参照。

在九个近期世界模型中，静态记忆最好的 HY-WorldPlay 仅使 31.7% 的指定事件真正开始；所有模型的记忆均随返回次数增加而衰减。没有模型在四个维度上全面领先。

1什么是世界记忆

自回归视频生成的时长与稳定性不断提高，相机与动作控制也日益精确，“视频世界模型”已可支持在生成场景中探索数十秒。探索过程中，画面内容不断移出和移入视野。本文将在这些中断下保持已确立内容、并使其连贯演化的能力称为世界记忆。

世界记忆包括两部分。静态记忆：人物的身份与衣着、物体的外观与形状、房间的布局与深度，再次观察时均应保持不变。动态记忆：视线移开期间，正在发生的事件应持续发生，视线返回时应能看到其结果。帧级画质与局部平滑度均无法反映这两方面。

已有评测基准分别考察过其中部分方面，如回访一致性、无人观察时的状态演化，近期也有基准测试多轮循环后的回忆能力。WorldMemBench 将这些方面整合在一起，覆盖长间隔回访、多次回访、状态演化与物理一致性，并在同一批 rollout 上同时测量相机控制和视频质量。

2离开与回访

每个样例以一帧条件帧为起点，即初始视图 V。随后相机按预设路径离开并返回，分别记为离开 Di 和回访 Ri。旋转类轨迹中，相机位置固定，左右转动（yaw）或上下转动（pitch）；平移类轨迹中，相机朝向不变，沿正方形移动一周。图 1 播放基准中的真实 rollout，均由 LingBot World v2 生成。

260 个样例，分属 23 个类别

静态记忆集共 200 个样例，其中人物 60 个、物体 70 个、环境 70 个；动态部分另有 60 个样例，涵盖运动、组装、移除、形变、转移、反应和热变化七类状态变化。视频质量在全部 200 段静态 rollout 上评测，相机跟随在其中轨迹适合位姿估计的 85 段上评测。

静态记忆的评分

静态内容的每次回访均与初始视图中的固定参考比较，而非与上一次返回比较，以免误差借缓慢漂移逃过检测。分数先在各次回访上平均，再在各目标上平均；按计划应有但缺少有效观测的回访记为 0 分。

  • 人物：身份采用 ArcFace 人脸嵌入衡量，外观采用人物掩码区域内的 DINOv2 特征衡量。
  • 物体：每次返回时通过检测与视频分割重新定位目标；外观采用掩码内的 DINOv2 特征衡量，几何则在归一化位置与尺度后计算轮廓的 IoU。
  • 环境：选取相机朝向最接近起始朝向的返回帧，可见内容采用全局 DINOv2 特征衡量；相对深度顺序采用两张深度图的 Spearman 相关系数衡量；3D 结构则将两张深度图投影到同一球面网格上，比较重建表面。

动态记忆的评分

动态事件无法按与首帧的相似度评分，因为正确的画面本应与首帧不同。因此，每个动态样例均规定初始状态、动作和预期的下一状态。评分时，视觉语言模型 Qwen3.8-27B 首先判断事件是否在画面中明显开始；若未开始，该样例记 0 分。若已开始，再回答八道带固定参考答案的是非题，返回进展、状态保持、最终状态以及因果或物理一致性各两题。图 3 展示一个真实样例。

3九个模型，四个维度

参评模型共九个：HY-WorldPlay、Matrix-Game 3 和 3.5、SANA-WM、YUME、LingBot World 和 LingBot World v2、Evoke、DreamX World。各模型均采用官方发布版本的默认设置并固定随机种子，基准中的相机轨迹转换为各模型自身的控制格式。

静态记忆与动态记忆是两种不同的能力。HY-WorldPlay 在全部七项静态记忆指标上均居首位，从人物身份（0.828）到环境重建（0.619）均是如此，但其动态记忆得分仅为 0.294，指定事件中仅 31.7% 真正开始。动态记忆领先的是 LingBot World（0.808）和 YUME（0.775），二者的静态指标均处于中游。没有模型在两方面同时领先：保持世界不变与使世界持续变化相互制约，见图 5。

相机跟随的表现与记忆相对独立。Matrix-Game 3 的平移误差最低（0.424），HY-WorldPlay 的旋转误差最低（0.417）；DreamX World 两项误差均最高，其环境深度与重建得分也最低。相比之下，视频质量在模型间的差异远小于记忆指标，也难以反映记忆水平。

4记忆随返回次数衰减

第一次返回表现良好，仅说明模型能够恢复一次视角，并不说明这种恢复能够持续。在 LRLRLR 轨迹下，从第一次到第三次返回，九个模型的平均分在七项静态指标上全部下降：物体外观下降 0.229，人物身份下降 0.217，物体几何下降 0.205，环境重建下降 0.196。就单个模型而言，在人物、物体、可见内容和重建指标上，所有模型第三次返回的得分均低于第一次。

两方面因素相互叠加。其一，返回视角本身存在漂移：三次返回的平均旋转误差依次为 0.430、0.502 和 0.530。其二，所有模型均采用自回归生成，早期误差会传递到后续帧。仅分析离开与返回均满足位姿标准的 431 段环境 rollout，下降依然存在：可见内容、深度顺序和重建分别下降 0.152、0.135 和 0.139。

改变方向后返回更加困难。LRLR 与 LRUD 的第一次返回相同，区别在于第二次：LRLR 仍左右转动，LRUD 改为上下转动。沿新轴返回时，各项静态指标的平均下降幅度均更大；63 个“模型–指标”组合中有 50 个呈现这一现象，环境可见内容记忆额外下降 0.152。

5上下文历史帧的选择

WorldMemBench 对各维度分别评分，因而可用于诊断模型设计。实验固定 LingBot World v2 及全部生成设置，比较三种无需训练的历史帧选择策略：全部历史（FullKV）、仅保留最近窗口（Sliding），以及最近帧加按视场检索的视角相关历史（FoV）。后两种策略的预算相同。

FoV 在四项动态子指标和两项人物指标上均优于全部历史，而全部历史在物体外观、物体几何和环境可见内容上仍占优。两种限定预算的策略速度更快：每段视频分别耗时 262.7 秒和 260.4 秒，全部历史为 322.2 秒，分别加速约 1.23 倍和 1.24 倍。将最近上下文与视角相关历史相结合是一种较优的折中，WorldMemBench 还能揭示每种选择具体有益于哪一类记忆。

6自动评分与人工判断的一致性

静态记忆方面，三名标注者盲评了 504 对 rollout。在有明确胜负的样本对上，自动指标与多数标注者判断的一致率为 78.5% 至 92.5%；模型排名与人工胜率的相关系数最高达 ρ = 0.988，对应环境可见内容记忆。动态记忆方面，三名标注者回答了 50 个样例的全部 400 道检查题，VLM 评判给出的总分与人工总分的 Spearman ρ 为 0.732，PLCC 为 0.808。因果与物理类问题最难判断，ρ 为 0.401。
